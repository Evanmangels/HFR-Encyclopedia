# HFR Encyclopedia v0.5 — Readable Article Sidebar

## Purpose

Correct the article-layout conflict introduced by the compact Wikipedia-style image treatment in v0.4.

## Changes

- Combined the main article image or automatic image placeholder and the fact-summary infobox into one right-side reference stack.
- Positioned the image above the factoid table.
- Removed the competing independent floats that squeezed overview text into an unreadable column.
- Limited the combined sidebar to 22 rem or 38% of article width.
- Added full-width mobile stacking while preserving image-first order.
- Updated the site, footer, homepage release section, and package naming to v0.5.

## Canon impact

None. This release changes presentation only.
