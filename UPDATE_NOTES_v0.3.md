# HFR Encyclopedia v0.3 — The Atlas Interface

Release date: 2026-07-24

## Interface overhaul

- Rebuilt the visual identity around an archival command-room and industrial-cartographic style.
- Redesigned the header, tabs, navigation, content shell, typography, cards, buttons, tables, admonitions, article infoboxes, and footer.
- Improved both light and dark modes.
- Added responsive layouts for desktop, tablet, and mobile screens.
- Added a custom HFR shield, compass, and open-book logo.

## New visual-placeholder system

- Added automatic category-specific feature-image positions to substantive articles.
- Added suggested asset filenames inside automatic placeholders.
- Added automatic three-position visual dossiers before canon/source sections.
- Added special visual prompts for polities, wars, history, world pages, languages, places, cultures, and religions.
- Added rules that suppress automatic placeholders when curated images or galleries are present.

## Homepage redesign

- Rebuilt the homepage as an archive command center.
- Added a reserved position for the definitive 1604 ATL world map.
- Added archive statistics, stronger exploration routes, and a redesigned editorial snapshot.
- Added the complete “What’s New in v0.3” section.

## Navigation and usability

- Added a reading-progress bar.
- Added article-type masthead labels.
- Improved active-navigation markers.
- Added persistent v0.3 identification in the footer.
- Added the Image & Visual Guide to Reference navigation.

## New documentation

- `docs/reference/image-guide.md` explains image naming, replacement classes, gallery behavior, recommended formats, accessibility, and visual canon control.

## Content policy

No lore or geopolitical canon was changed in v0.3. This release changes presentation, navigation, image readiness, and editorial tooling only.
