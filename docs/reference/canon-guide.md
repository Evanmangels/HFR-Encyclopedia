# Canon and Source Guide

This page governs how encyclopedia articles handle conflicting, incomplete, or evolving HFR material.

## Core principle

The encyclopedia must never silently convert an inference, old draft, or attractive idea into established canon. Every substantive claim should be traceable to a current ruling, an authoritative source, or an explicitly labeled derivation.

## Current hierarchy

1. **Current project-chat corrections and explicit user corrections** outrank all documents.
2. ***Rome (With Colonialism)*** is the main guide to the setting's general feel, civilizational logic, historical trajectory, colonial development, and intended direction. Material farther down or later in that document is generally more authoritative than earlier material. It may outrank *Master Doc V3* when it reflects a newer or clearer intended direction.
3. ***Master Doc V3*** remains the main organized setting guide, but it is not automatically the final authority over later or clearer material in *Rome*.
4. ***Master Doc V2*** may supply older structured detail only when compatible with current rulings, *Rome*, and *Master Doc V3*.
5. ***AS Language Book*** is the specialist authority for Atlantic Standard, language, spelling, pronunciation, grammar, and naming questions.
6. ***HFR_AI_Transfer_Instructions*** provides workflow and project-handling instructions, but substantive current corrections still prevail.

!!! note "Context matters"
    The hierarchy is not merely a mechanical list. A specialist language source may outrank a general history document on pronunciation, while a current political retcon outranks every older source on the affected political fact.

## Status labels

<span class="canon-badge status-hard">Hard canon</span>
: Explicitly established and current.

<span class="canon-badge status-derived">Derived canon</span>
: A necessary or very strong consequence of hard canon, identified as an inference.

<span class="canon-badge status-soft">Soft canon</span>
: Present in current material but still open to revision or insufficiently developed.

<span class="canon-badge status-proposal">Proposal</span>
: New material offered for approval. It must not appear elsewhere as established fact.

<span class="canon-badge status-incomplete">TBD / incomplete</span>
: Information has not yet been established or imported.

<span class="canon-badge status-obsolete">Obsolete</span>
: Superseded material retained only for editorial history.

## Conflict procedure

When two sources disagree:

1. Record the exact disagreement.
2. Determine whether a current correction already resolves it.
3. Apply the hierarchy with attention to subject-matter authority and recency.
4. Preserve useful superseded material in an editorial note or archive.
5. Do not fill resulting gaps through invention.
6. Add an open question when a ruling is still required.

## Article-level source notes

Major articles should end with a source table:

## Known current correction

By **1604 ATL**, Egypt and the Abbasids no longer exist as independent states; both are part of the **Hijez Sultanate**. Any older Abbasid–Egyptian rivalry framework for that date is obsolete.
